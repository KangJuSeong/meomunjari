# 신청서 v13 · 5. 개발계획

## 구현 구조

- **차량용 앱** — Kotlin과 Jetpack Compose로 구현했다. 운전자는 한 앱에서 차박지를 찾고, 출발 전 예상 잔량을 확인하고, 주차 후 잠자리를 준비하고, 아침에 지난밤의 기록을 돌아본다. 화면, 판단 로직, 데이터 저장소를 구분하고 차량 상태·위치·내비는 각각 독립된 인터페이스로 연결했다.
- **두 가지 실행 환경** — 일반 Android 기기에서는 `mock` 빌드의 가상 차량 콘솔로 위치·기어·배터리·온도를 바꿔 전체 과정을 시연한다. `pleos` 빌드는 같은 화면을 Pleos Connect의 차량 신호와 내비에 연결한다. 1차 제출본은 별도 서버 없이 실행되며, 두 빌드 모두 앱에 담긴 스팟·기온·방문 기록 예시를 사용한다.

## SDK 및 데이터 활용

- **위치·길안내** — FusedLocation으로 주변 스팟을 찾고, 스팟 반경 안에서 5초간 주차 상태가 유지되면 방문을 인증한다. NaviHelper로 선택한 차박지를 차량 내비 목적지로 설정하거나 안내를 취소한다. 앱에 표시하는 남은 거리와 주행 시간은 현재 좌표에서 차박지까지의 직선거리를 보정하고 평균 시속 45km를 적용한 추정치다.
- **출발 전 에너지 예측** — 현재 배터리 잔량, 예상 주행 거리, 차량 전비와 배터리 용량으로 도착 잔량을 계산한다. 목업에서는 2021 아이오닉 5 AWD 72.6kWh 히트펌프 차량의 외기 0°C·AUTO 22°C 공개 난방 시험값을 사용해, 도착 직후부터 예정한 기상 시각까지의 소모량을 추정한다. 초기 난방 시간과 대기전력은 목업 가정이다. 차량이나 기온 조건에 맞는 자료가 부족하면 기상 잔량에 ‘예측 자료 부족’을 표시한다. Pleos 빌드는 연결 차량의 시험 대상 트림을 식별하기 전까지 기상 잔량 예측을 보류한다.
- **일출 주차·차박 세팅** — 차박지 좌표와 날짜로 가까운 일출의 시각과 방위를 계산한다. 운전자가 앞유리나 트렁크를 고르면 차 앞머리를 둘 방향을 안내하고, 주차 직전 이동 궤적이 충분하면 현재 방향도 함께 보여준다. 도착 후에는 ‘고수의 세팅’에서 내 차가 지원하는 공조·좌석별 등받이·창문·조명을 적용한다. 개인 시트 메모리 번호는 공유 세팅에서 제외한다.
- **밤사이 기록·스팟 등록** — 기록에 동의하면 Vehicle SDK의 실내 온도·공조 상태·배터리 또는 연료 잔량·와이퍼 상태와 AAOS의 외기온을 이용해 차박 리포트를 만든다. 아침에는 예상 잔량과 실제 종료 잔량, 머문 시간을 함께 본다. 새 스팟은 현재 위치에서 등록하며, 브이월드 응답 형식으로 가공한 광주시 상수원보호구역 경계 안에서는 등록을 막는다. 등록 가능한 곳에는 현장 안내를 확인하도록 알린다.

## 권한과 차량별 제약

- AAOS의 기어·속도 신호로 주행과 주차를 구분한다. 주행 중에는 검색·리뷰 입력을 숨긴다. 차량 제어 전에는 주차 상태와 지원 기능·좌석별 조절 범위를 확인하고, 도어 열기는 실행 직전 운전자에게 다시 묻는다. 차박 중 배터리가 운전자가 정한 보호 기준에 닿으면 공조 끄기를 요청한다.
- 차급과 배터리 용량은 차량 프로필을 기준으로 한다. 실내·외 온도와 차량 상태는 읽을 수 있는 항목만 기록한다. 에뮬레이터에서 확인한 기능도 실차에서는 차종별 권한과 제어 범위를 별도로 검증한다.

## 진행 현황과 일정

- **구현·시연 완료** — 서버 없는 목업에서 테마·차급 검색, 출발 전 잔량 확인, 차박지 길안내, 도착 인증, 일출 주차, 세팅 적용, 종료 리포트와 후기 작성을 연결했다. 스팟 등록·보호구역 차단·해시태그·뱃지 및 등급도 구현했다. Pleos 공식 에뮬레이터에서 앱 실행과 차량 세팅 화면을 확인했고, GitHub README에 기능별 화면과 시연 순서를 공개했다.
- **1차 제출 전** — 최신 APK 두 종에서 시연을 다시 진행한다. Pleos 에뮬레이터에서는 목적지 설정·취소, 주차 후 좌석별 세팅 적용 결과, 지원하지 않는 항목의 표시를 점검하고 제출용 시연 영상을 제작한다.
- **후속 개발** — 아이오닉 5 실차에서 같은 기상 시각의 예상 잔량과 실제 잔량 차이를 %p 단위로 측정한다. 오차를 확인한 조건부터 기상청 시간대별 예보를 연결하고 지원 차종을 확대한다. 스팟·리포트·리뷰를 다음 방문자와 공유할 서버를 구축하고, 브이월드 경계와 지자체·시설 운영 정보를 연동해 야영 제한 안내의 지역 범위를 넓힌다. 외부 캠핑 장비는 현재 리포트에 사용 내역을 남길 수 있으며, 직접 제어는 연동을 검증한 제품부터 추가한다.
