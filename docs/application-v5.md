# 신청서 v5 · ② “내 차로 하룻밤 머물 수 있을까?” 에너지 예측

- 현재 잔량과 남은 거리, 내 차의 전비와 배터리 용량으로 도착 잔량을 추정한다. 기상 시 잔량은 내 차가 비슷한 외기온과 공조 설정에서 밤새 쓴 배터리 기록을 우선해 추정할 계획이다. 비교할 기록이 부족하면 ‘측정중’으로 표시한다.
- 기상 시 예상 잔량이 가까운 충전소까지 갈 전력과 여유분에 못 미치면, 출발 전에 들를 수 있는 경유 충전소와 예상 충전 시간을 제안한다. 운전자는 직행과 충전 경유의 도착 시각과 기상 시 예상 잔량을 비교해 선택한다.

## v4에서 바뀐 내용

기존 시연은 같은 스팟·월의 전기차 리포트로 야간 소모를 계산한다. 실차 적용 계획에서는 운전자 차량의 외기온·공조 설정이 비슷한 기록을 우선한다. 실차 검증 전에는 특정 온도의 소비전력이나 고정 충전 시간을 보장할 수 없다.

일부 차량의 순정 화면은 공조 소비전력을 표시한다. 대상 차량에서 주차 중 외부 앱에 이 값이 제공되는지는 별도 확인이 필요하다. 잔량 차이만 측정할 수 있으면 공조를 포함한 차량 전체 소모로 기록한다. ### v4 문구

- 현재 배터리에서 차박지까지 주행에 쓸 양을 빼 도착 잔량을 구한다. 도착 후 8시간 동안 시간대별 기온이 10°C 미만이면 난방을 쓴다고 가정한다. 같은 스팟·같은 달의 전기차 기록으로 난방과 대기에 들 전력을 추정해 아침 잔량을 표시한다.
- 유효한 전기차 기록이 0~1건이면 “측정중”, 2건이면 참고치로 표시한다. 아침 잔량이 인근 충전소까지 갈 전력과 여유분 15%p에 못 미치면 도달 가능한 경유 충전소와 충전 시간을 제안한다. 운전자가 선택하면 차박지를 최종 목적지로 유지한다.
