# v2.2 기상 시각에 맞춘 잔량 예측

| 항목 | v2.1 | v2.2 |
| --- | --- | --- |
| 차박 계획 | 도착 후 8시간 | 전기차 이용자가 스팟 상세나 도착 화면에서 기상 시각을 분 단위로 선택한다. 미설정 시 8시간을 적용한다. |
| 출발 전 | 고정 시간으로 아침 잔량과 충전 권고 계산 | 직행 예상 도착부터 기상까지의 공조·대기 소모를 계산한다. 시각을 바꾸면 예상 잔량, 충전 필요 여부, 권장 충전 시간이 함께 갱신된다. |
| 차박 중 | 8시간까지의 남은 소모 계산 | 실제 차박 시작을 기준으로 기상까지의 시간을 확정한다. 남은 시간의 예상 소모에 현재 공조 상태와 배터리 보호 결과를 반영한다. |
| 종료 리포트 | 8시간 예측과 종료 잔량 비교 | 시작 때 선택한 기상 시각의 예측과 종료 잔량을 비교한다. 실제 체류 시간이 계획과 다르면 안내한다. |

기기 현지 시각을 사용한다. 23:00에 시작해 06:30에 기상하면 7시간 30분이다. 도착과 기상 시·분이 같으면 다음 날 같은 시각으로 계산한다. 설정은 이번 차박에 적용하고 종료하면 초기화한다.

1차 시연은 스팟별 시간대 목업 기온 24개를 사용한다. 실제 기상청 예보와 순정 내비 도착 예정 시간 연동은 후속 범위다. 출발 전 충전 권고는 직행했을 때의 예상 잔량을 기준으로 한다.

## 확인 결과

mock 28건과 Pleos 24건의 단위 테스트가 통과했다. 자정을 넘기는 일정, 30분 연장 시 충전 권고 전환, 자료 부족, 최초 예측을 담은 종료 리포트를 확인했다. 별도 Robolectric 화면 테스트 2건에서 실제 시간 선택 창으로 시각 지정과 기본값 복귀, 잔량 갱신, 경유 안내, 조기 종료 표시를 확인했다.
