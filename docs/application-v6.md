# 신청서 v6 · ② “내 차로 하룻밤 머물 수 있을까?” 에너지 예측

- 현재 잔량에서 남은 거리와 내 차의 전비로 계산한 주행 소모분을 빼 도착 잔량을 구한다. 도착부터 기상까지는 시간대별 외기온과 실내 설정 온도를 바탕으로, 차종별 공조 전력과 대기 전력에 사용 시간을 곱해 야간 소모량을 구한다. 이를 내 차의 사용 가능 배터리 용량에 맞춰 기상 시 예상 잔량으로 표시한다.
- 기상 시 예상 잔량이 다음 충전소까지 갈 전력과 여유분에 못 미치면, 도달 가능한 경유 충전소와 예상 충전 시간을 제안한다. 운전자는 직행과 충전 경유의 도착 시각과 기상 시 예상 잔량을 비교해 선택한다.

## 계산 기준

- 주행 소모량(kWh) = 경로 거리(km) ÷ 전비(km/kWh).
- 야간 소모량(kWh) = 각 구간의 (평균 공조 전력 + 공조를 제외한 대기 전력)(kW) × 구간 시간(h)의 합. 기상 시 예상 잔량(%)은 도착 잔량(%)에서 야간 소모량 ÷ 사용 가능 배터리 용량 × 100을 뺀 값이다.
- 초기 냉난방과 온도 유지 구간을 구분한다. 차종별 평균 전력 범위는 외기온·초기 실내 온도·목표 온도에 맞는 제조사 자료나 별도 전력 시험으로 확보할 계획이다. 지원 근거가 부족하면 예측 자료 부족으로 표시한다. 예측에는 과거 차박 리포트가 필요하지 않다.

## v5에서 달라진 점

기존에는 비슷한 밤의 내 차 배터리 기록을 예측에 사용하도록 기획했다. v6에서는 첫 방문부터 차량별 전력과 시간을 이용해 계산하며 차박 종료 기록은 예측 오차를 확인하는 데 활용한다. 현재 배포한 목업의 계산 방식과 구분하기 위해 신청서 6번의 후속 개발 설명도 수정했다. [v5 문구](application-v5.md)
