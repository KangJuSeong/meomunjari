# 브이월드 야영 제한 판정 목업 v1

스팟 등록 화면은 현재 좌표와 국토교통부 브이월드의 상수원보호 레이어를 대조하는 흐름을 재현한다. 수도법 시행령 제12조 제1항 제3호에서 이 구역의 야영을 금지하므로, 경계 안에서는 등록을 막는다. 경계 밖이나 자료가 없는 위치에서는 ‘야영 가능 여부 확인 필요’를 표시한다. 이용자의 금지 장소 신고는 별도로 관리한다. [수도법 시행령 제12조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1015475209)

## 동봉한 예시 데이터

앱은 외부 호출 없이 `app/src/main/assets/mock/vworld_water_protection_mock.json`을 읽는다. 브이월드 2D 데이터 API 2.0의 `GetFeature` 응답 구조인 `response → result → featureCollection → features`에 두 예시를 담았다. 페이지 개수와 응답 시간은 목업 값이다. [브이월드 상수원보호 API 명세](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=um710)

| 샘플 | 데이터 출처와 처리 |
|---|---|
| 경상남도 진주시 | 공식 명세의 예시 속성(관리번호 `53100004817020040000UMI1000001218`, 고시년도 2004, 번호 264)을 사용했다. 명세에는 좌표 대신 `POLYGON(…)`으로 표시되어 목업에서는 `geometry: null`로 담았다. GPS 판정 대상에서 제외한다. |
| 경기도 광주시 | 같은 레이어명 `LT_C_UM710`의 광주시 공개 SHP를 WGS84로 변환했다. 광주시 원본 관리번호 `14800004161020200066UMI1000001000`, 용도코드 `UMI100`, 외곽선 1개, 내부 제외 영역 2개와 좌표 1,774개를 보존했다. 앱 화면에서 출처와 원자료 기준일(2025-11-24)을 표시한다. [광주시 원본](https://www.data.go.kr/data/15120793/fileData.do) |

## 이후 실제 API 연결

브이월드 인증키와 등록 도메인을 준비하고 `https://api.vworld.kr/req/data`에 아래 조건으로 조회한다. 현재 목업은 라이브 응답을 저장한 파일이 아니다. [요청 파라미터와 응답 명세](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=um710)

| 파라미터 | 값 |
|---|---|
| service / version / request | data / 2.0 / GetFeature |
| data / crs / format | LT_C_UM710 / EPSG:4326 / json |
| geomFilter | POINT(경도 위도) |
| attrFilter | ucode:=:UMI100 |
| geometry / attribute | true / true |

좌표는 경도·위도 순서다. 응답이 성공하고 용도코드가 `UMI100`인 Polygon 또는 MultiPolygon에만 위치 판정을 적용한다. 조회 실패, 결과 없음, 좌표 누락, 다른 용도코드는 등록 차단 근거로 사용하지 않는다. 이 레이어로 조회할 수 있는 범위는 상수원보호구역이다. 브이월드 2D 데이터 API 목록의 서비스명 158건을 확인한 결과(2026-11-14), ‘야영’, ‘차박’, ‘캠핑’을 명칭에 넣은 서비스는 확인되지 않았다. [브이월드 2D API 목록](https://www.vworld.kr/dev/v4dv_2ddataguide2_s001.do)

## 재현 방법

가상 차량 콘솔에서 기어를 P로 바꾸고 아래 위치에서 ‘새 스팟 등록’을 연다.

| 위치 | 위도, 경도 | 화면과 등록 결과 |
|---|---|---|
| 경기 광주 상수원보호구역 | 37.48634563, 127.31812732 | 보호구역과 근거 표시, ‘등록하기’ 비활성 |
| 고성 봉포 해변 공터 (미등록) | 38.2482, 128.5668 | 야영 가능 여부 확인 필요, 주차 후 새 스팟 등록 가능 |
| 광주시 경계의 첫 번째 제외 영역 (단위 테스트) | 37.46955990, 127.31228707 | 이 보호구역에 의한 차단 없음 |
| 광주시 경계의 두 번째 제외 영역 (단위 테스트) | 37.49528264, 127.30125165 | 이 보호구역에 의한 차단 없음 |
